# Mini LLM

A series of text generation models that will build into a miniature LLM

## Planned sections

1. An N-gram next character/word predictor
2. A single-headed self-attention block
3. Multi-headed attention + single transformer block
4. A full transformer model with multiple blocks and positional encoding

## Dependencies

Created with `Python 3.13`

Libraries used:

- `pytorch`: tensor operations and gradient descent
- `unidecode`: used to clean text by converting from utf-8 to ascii
